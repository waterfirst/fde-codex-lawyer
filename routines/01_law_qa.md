# 루틴 ① 법령 Q&A

## 목적
의뢰인/변호사의 질문 → 관련 법령을 법제처 MCP로 검색 → 조문 인용 + 쉬운 설명으로 즉답.

## 입력
- 질문(익명화된 사실관계). 예: "온라인몰이 고객 동의 없이 마케팅 문자를 보냈다. 어떤 법 위반인가?"

## 절차 (Codex에 이렇게 지시)
> AGENTS.md 규칙을 따른다. 아래 질문에 대해 korean_law MCP로 관련 법령을 검색하고,
> 결론 → 근거 조문(조·항·호 인용) → 쉬운 설명 → 예외/주의 → 면책 순으로 답하라.
> 질문: "<여기에 질문>"

## 출력
- 결론 / 인용 조문 / 평이한 설명 / 주의 / 면책 한 줄.

## 실습 팁
- 변호사가 직접 질문을 바꿔가며 3~4개 돌려본다.
- "근거 조문이 안 나오면 확인 불가로 답하라"를 지켜보게 한다(환각 차단 체감).

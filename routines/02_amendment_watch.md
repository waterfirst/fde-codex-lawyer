# 루틴 ② 개정 모니터

## 목적
변호사의 관심 법령(예: 개인정보보호법, 전자상거래법)의 **변경점을 주기적으로 요약**해서 받는다.

## 입력
- 관심 법령 목록. 예: ["개인정보보호법", "전자상거래 등에서의 소비자보호에 관한 법률"]
- 기준 시점(지난번 확인일).

## 절차 (Codex에 이렇게 지시)
> AGENTS.md 규칙을 따른다. korean_law MCP로 아래 법령들의 최신 상태(시행일·개정 이력)를 조회하고,
> 기준일 이후 바뀐 조문이 있으면 "법령명 / 변경 조문 / 무엇이 어떻게 바뀌었나 / 실무 영향"으로 요약하라.
> 변경 없으면 '변경 없음'으로 표기. 결과를 amendment_report.md 로 저장하라.
> 법령: [ ... ], 기준일: YYYY-MM-DD

## 출력
- `amendment_report.md` — 법령별 변경 요약표(변경 없으면 없음 표기).

- 주 1회 정기 실행(습관화). 자동화는 다음 단계.
